  <action>
    **Create `src/core/land/settlement-types.ts`:**
    Define the discriminated union type system following the IndivisibleResolution pattern from `src/core/assets/types.ts`:
    - `LandSettlementMethod = 'sell_split' | 'physical_division' | 'buyout' | 'joint_ownership'`
    - `SellSplitSettlement { method: 'sell_split'; actualSalePrice: number | null }` -- null means use property value
    - `SubParcel { id: string; name: string; areaSqft: number; areaInputUnit: LandUnit; appraisedValue: number }`
    - `PhysicalDivisionSettlement { method: 'physical_division'; subParcels: SubParcel[] }`
    - `BuyoutSettlement { method: 'buyout'; buyerHeirType: HeirType; useInstallments: boolean; installmentCount: number }` -- installmentCount preset options: 3, 6, 12, 24
    - `JointOwnershipSettlement { method: 'joint_ownership'; incomeAmount: number | null; incomeType: 'rent' | 'crop' | null; incomePeriod: 'monthly' | 'yearly' | null }`
    - `LandSettlement = SellSplitSettlement | PhysicalDivisionSettlement | BuyoutSettlement | JointOwnershipSettlement`

    **Create `src/core/land/settlement.ts`:**
    Pure calculation functions (no UI, no store):
    1. `calculateSellSplit(propertyValue: number, shares: ShareResult[]): { heirType: HeirType; amount: number }[]` -- filters blocked shares, uses Math.round(value * share.totalShare.valueOf())
    2. `computeSubParcelTargets(propertyValue: number, shares: ShareResult[]): { heirType: HeirType; targetValue: number }[]` -- same math as sell split, gives per-heir-group target values for physical division
    3. `calculatePhysicalDivisionCompensation(subParcels: SubParcel[], targets: { heirType: HeirType; targetValue: number }[]): { totalSubParcelValue: number; targetTotal: number; difference: number }` -- computes difference between total sub-parcel appraised value and property value for compensation display
    4. `calculateLandBuyout(propertyValue: number, buyerHeirType: HeirType, shares: ShareResult[], useInstallments: boolean, installmentCount: number): LandBuyoutResult` -- reuses `calculateBuyout()` from `src/core/assets/indivisible.ts`, extends with installment plan. `LandBuyoutResult extends BuyoutCalculation { installmentPlan: { perInstallment: number; count: number; totalOwed: number } | null }`
    5. `calculateInstallments(totalCompensation: number, installmentCount: number): { perInstallment: number; count: number; totalOwed: number }` -- `Math.round(total / count)` per installment, no interest (Islamic finance compliant)
    6. `calculateOwnershipShares(shares: ShareResult[]): { heirType: HeirType; percentage: number }[]` -- `Math.round(share.totalShare.valueOf() * 10000) / 100` for 2 decimal places
    7. `calculateIncomeDistribution(incomeAmount: number, shares: ShareResult[]): { heirType: HeirType; amount: number; percentage: number }[]` -- proportional income distribution

    **Create `src/core/land/__tests__/settlement.test.ts`:**
    Write tests FIRST (TDD). Use mock ShareResult arrays with real Fraction objects (import from fraction.js). Test all 7 functions with at least 2 test cases each covering normal and edge cases. Test that blocked shares are excluded. Test installment rounding. Test that ownership percentages sum to approximately 100%.
