Create `src/core/land/division.ts` with these exports:

**Types:**
```typescript
export interface DivisionGroup {
  heirType: HeirType
  label: string           // from HEIR_TYPE_LABELS
  count: number           // individual heirs in this group
  targetValue: number     // Math.round(totalShare.valueOf() * totalEstateValue)
  assignedProperties: string[]  // property IDs
  assignedValue: number   // sum of computePropertyTotal for assigned properties
  cashAdjustment: number  // Math.round(assignedValue - targetValue)
}

export interface CashCompensation {
  fromGroup: HeirType     // overfilled group
  toGroup: HeirType       // underfilled group
  amount: number          // BDT
}

export interface DivisionResult {
  groups: DivisionGroup[]
  totalEstateValue: number
  compensations: CashCompensation[]
}
```

**Functions:**

1. `divideParcels(properties: Property[], shares: ShareResult[], totalEstateValue: number): DivisionResult`
   - Filter shares to active only (shareType !== 'blocked')
   - Create one DivisionGroup per active share with targetValue = Math.round(share.totalShare.valueOf() * totalEstateValue)
   - Sort properties by computePropertyTotal descending (largest first)
   - For each property, find the group with the largest (targetValue - assignedValue) gap and assign
   - After all assignments, compute cashAdjustment = Math.round(assignedValue - targetValue)
   - Call calculateCompensations on the groups
   - Return DivisionResult

2. `calculateCompensations(groups: DivisionGroup[]): CashCompensation[]`
   - Separate groups into overfilled (cashAdjustment > 0) and underfilled (cashAdjustment < 0)
   - Greedily match overfilled to underfilled: for each overfilled group, distribute its surplus to underfilled groups
   - Each compensation entry has fromGroup, toGroup, and amount

3. `qurahShuffle(groups: DivisionGroup[]): Map<number, HeirType>`
   - Group indices by targetValue (groups with same target are interchangeable)
   - For each set of same-target indices, collect their heirTypes and Fisher-Yates shuffle the assignment
   - Groups with unique targetValue keep their heirType unchanged
   - Return Map from group index to assigned HeirType

4. `moveParcel(result: DivisionResult, propertyId: string, fromHeirType: HeirType, toHeirType: HeirType, properties: Property[]): DivisionResult`
   - Find fromGroup and toGroup by heirType
   - Remove propertyId from fromGroup.assignedProperties, add to toGroup.assignedProperties
   - Recalculate assignedValue for both groups using computePropertyTotal lookups
   - Recalculate cashAdjustment for all groups
   - Recalculate compensations
   - Return new DivisionResult (immutable -- do not mutate input)

Import HEIR_TYPE_LABELS from `@/core/utils/display` for the label field.

**State:**
```typescript
interface DivisionState {
  divisionResult: DivisionResult | null
  qurahMap: Map<number, HeirType> | null  // null = not yet drawn
  isRevealed: boolean                      // Qurah results revealed?
  revealedGroupCount: number               // for staggered reveal (0 to N)
  propertyFingerprint: string | null       // JSON hash to detect stale state
}
```

**Actions:**
```typescript
interface DivisionActions {
  computeDivision: () => void       // reads wizardStore.getState() for properties, results, totalEstateValue; calls divideParcels
  performQurah: () => void          // calls qurahShuffle on current groups, sets qurahMap, resets reveal state
  revealNextGroup: () => void       // increments revealedGroupCount by 1
  revealAll: () => void             // sets revealedGroupCount to total groups
  moveParcel: (propertyId: string, fromHeirType: HeirType, toHeirType: HeirType) => void  // calls moveParcel from division.ts, clears qurahMap (manual assignment invalidates Qurah)
  resetDivision: () => void         // clears all state to null/initial
  getDisplayGroups: () => DivisionGroup[]  // returns groups with Qurah mapping applied (if exists) -- remap heirType/label/count based on qurahMap
  isStale: () => boolean            // compares current propertyFingerprint with computed fingerprint from wizardStore
}
```

**Implementation details:**
- `computeDivision` reads from `useWizardStore.getState()` non-reactively. Gets `properties`, `results`, `totalEstateValue`. Calls `divideParcels(properties, results.shares, totalEstateValue)`. Stores result and computes propertyFingerprint as `JSON.stringify(properties.map(p => ({ id: p.id, v: computePropertyTotal(p) })))`.
- `performQurah` calls `qurahShuffle(divisionResult.groups)`, stores the map, sets `isRevealed: false`, `revealedGroupCount: 0`.
- `getDisplayGroups` is a computed getter: if qurahMap is null, return groups as-is. If qurahMap exists, remap each group's heirType, label, and count using the qurahMap and the original groups' share data.
- `isStale` recomputes the fingerprint from current wizardStore state and compares to stored fingerprint.
- Do NOT persist this store to localStorage. It's derivable and ephemeral.
- Follow the same Zustand v5 `create` pattern used in wizardStore and scenariosStore.
