      type: 'property' | 'movable'
      value: number           // BDT value

    export interface PdfDistributionGroup {
      heirType: string        // display label (from HEIR_TYPE_LABELS)

      targetValue: number
      assignedItems: PdfDistributionItem[]

    - Set `distribution` field in returned PdfData.
    - When distributionResult exists, do NOT set lotDivision (distribution supersedes it). When distributionResult is null/undefined and divisionResult exists, keep existing lotDivision behavior.

    - Section header: "Distribution Summary" with same styling as PdfLotDivisionSection.
    - For each group: Sub-header with heirType label, count, target value, assigned value, cash adjustment.
    - Table of assigned items with columns: Item, Category, Value (BDT).
    - Items sorted by value descending within each group.
    - Compensation pairs section at bottom (same pattern as PdfLotDivisionSection): "Son pays Daughter BDT X" format.
    - Use existing pdfStyles, pdfColors, and layout patterns.
    - Add `break` prop for page break hints on long sections.
