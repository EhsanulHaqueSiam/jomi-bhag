    **AssetCard.tsx:** Draggable card for any asset item.
    - Uses `useDraggable` from @dnd-kit/core with item.id as draggable id.
    - Props: `item: DistributionItem`, `groupId: string` (heirType of containing column), `isOverlay?: boolean` (for DragOverlay rendering).
    - Display: Category color badge (left border or small icon area) + label + formatted BDT value.
    - Category color scheme (Claude's discretion per CONTEXT.md):
      - residential: blue-100/blue-700, agricultural: green-100/green-700, commercial: purple-100/purple-700, mixed: gray-100/gray-700
      - gold_silver: yellow-100/yellow-700, cash: teal-100/teal-700, vehicle: indigo-100/indigo-700, jewelry: pink-100/pink-700
      - furniture: orange-100/orange-700, livestock: lime-100/lime-700, custom: slate-100/slate-700
    - Inline SVG icons per category (small 16x16): house for residential, tree for agricultural, building for commercial, coins for gold, banknote for cash, car for vehicle, gem for jewelry, sofa for furniture, etc.
    - When dragging: opacity-50 on the original (via isDragging from useDraggable). DragOverlay renders a copy with shadow-lg and ring-2 ring-emerald-400.
    - Size: Compact card (py-2 px-3) to fit many items in a column.

    **EquilibriumBar.tsx:** Animated progress bar at top of each column.
    - Props: `assignedValue: number`, `targetValue: number`.
    - Computes equilibrium using `getEquilibriumStatus(assignedValue, targetValue)` from algorithm.ts.
    - Renders a thin colored bar (h-1.5 rounded-full) inside a gray-200 track.
    - Bar width: `Math.min(percentage, 100)%` animated with motion/react spring.
    - Color mapping: balanced -> emerald-500/emerald border, close -> amber-400/amber border, off -> red-500/red border.
    - Below bar: text label "98% of target" in matching color. When delta > 0: "+BDT X over target" in red/amber text.
    - Top border-t-4 on the column card in matching color per CONTEXT.md decision.

    **HeirColumn.tsx:** Droppable column for one heir group.
    - Uses `useDroppable` from @dnd-kit/core with group.heirType as droppable id.
    - Props: `group: DistributionGroup`, `items: DistributionItem[]` (items assigned to this group).
    - Layout: rounded-xl border bg-white shadow-sm. When isOver (from useDroppable): border-emerald-400 bg-emerald-50/30.
    - Header: EquilibriumBar at top, then group label (h3 font-semibold) + heir count badge + target value (text-xs text-gray-500 "Target: BDT X").
    - Body: Scrollable (max-h-[400px] overflow-y-auto) list of AssetCard components with space-y-2.
    - Empty state: Dashed border placeholder "Drag items here" when no items assigned.

    **SummaryBanner.tsx:** Overall equilibrium status banner.
    - Props: `balancedCount: number`, `totalCount: number`.
    - When all balanced: green bg-emerald-50 border-emerald-200 with "All groups balanced!" text and a brief celebratory animation (motion/react scale pulse: scale 1 -> 1.02 -> 1 over 300ms, triggered via AnimatePresence).
    - When partially balanced: neutral bg-gray-50 with "3/4 groups balanced" text and a small progress indicator.
    - When none balanced: amber bg-amber-50 with "0/4 groups balanced - drag items to equalize" hint text.

    **DistributionControls.tsx:** Randomize + Undo buttons.
    - Props: `onRandomize: () => void`, `onUndo: () => void`, `canUndo: boolean`.
    - "Randomize" button: emerald-600 bg, shuffle icon (inline SVG), brief disabled state during animation (200ms setTimeout). Text "Randomize".
    - "Undo" button: ghost style, only visible when canUndo is true. Animated entrance (motion/react fade + slide from right, duration 200ms). Text "Undo".
    - Layout: flex items-center gap-2, right-aligned.

    **MobileFallback.tsx:** "Move to..." select for each item (alternative to DnD on mobile).
    - Props: `item: DistributionItem`, `currentGroupHeirType: HeirType`, `allGroups: DistributionGroup[]`, `onMove: (itemId, from, to) => void`.
    - Renders a native `<select>` element (matching Phase 9's ParcelRow pattern) with option for each group except current.
    - Visible below each AssetCard at all screen sizes (DnD and fallback coexist -- mobile users may prefer the select even if DnD works).

    **DistributionBoard.tsx:** Main DnD orchestrator.
    - Uses DndContext from @dnd-kit/core with sensors:
      - PointerSensor with activationConstraint: { distance: 5 }
      - TouchSensor with activationConstraint: { delay: 500, tolerance: 5 } (per CONTEXT.md 500ms long-press)
      - KeyboardSensor for accessibility
    - collisionDetection: closestCorners
    - State: `activeItem: DistributionItem | null` (for DragOverlay)
    - onDragStart: Set activeItem from the dragged id by looking up in items array.
    - onDragEnd: Determine source group (find group containing item.id in assignedItems) and destination group (from over.id which is the droppable heirType). If source !== dest, call distributionStore.moveItem(). Clear activeItem.
    - onDragOver: No action needed (we don't reorder within columns, just move between).
    - Layout: Responsive Kanban grid.
      - Mobile (default): grid-cols-1 (vertical stack)
      - Tablet (md): grid-cols-2
      - Desktop (lg): flex flex-row with horizontal scroll (overflow-x-auto), each column min-w-[280px] flex-shrink-0 lg:flex-1
    - DragOverlay: Renders AssetCard with isOverlay=true when activeItem is set. Uses `{ modifiers: [] }` (no axis restriction).
    - SummaryBanner positioned above the columns grid.

    **DistributionPage.tsx:** Page-level orchestrator.
    - Props: `onNavigate: (page: AppPage) => void`.
    - On mount: calls distributionStore.computeDistribution() if no result or isStale().
    - Header bar: "Asset Distribution" title + "Back to Results" button (same pattern as LotDivisionPage).
    - Renders DistributionControls (Randomize + Undo) below header.
    - Renders CompensationBanner from Phase 9 (reuse existing component, pass distributionResult.compensations).
    - Renders DistributionBoard as the main content.
    - Reads from useDistributionStore: distributionResult, previousSnapshot (for canUndo), and actions.
