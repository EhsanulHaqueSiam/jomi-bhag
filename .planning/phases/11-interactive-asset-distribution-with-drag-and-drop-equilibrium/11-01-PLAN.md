    export interface DistributionItem {
      id: string
      type: 'property' | 'movable'
      category: string       // property type or asset category
      label: string           // display name
      value: number           // BDT value
    }

    export type EquilibriumStatus = 'balanced' | 'close' | 'off'

    export interface EquilibriumResult {
      status: EquilibriumStatus

      delta: number           // assigned - target (positive = over, negative = under)

    **algorithm.ts:** Create pure algorithm functions.
    - `buildDistributionItems(properties, movableAssets)`: Converts Property[] and MovableAsset[] into DistributionItem[]. For properties, use `p.nickname || 'Property #N'` as label and `computePropertyTotal(p)` as value. For movable assets, use a getAssetLabel helper (switch on category: gold shows "Gold 5 vori 22K", vehicle shows description or type label, etc.) and `computeAssetValue(a)` as value.
    - `getEquilibriumStatus(assignedValue, targetValue)`: Returns { status, percentage, delta } per tolerance ranges (<=2% = balanced, <=5% = close, >5% = off). Handle targetValue===0 as balanced at 100%.
    - `smartShuffle(items, groups)`: Sort items by value descending. For each item, compute remaining capacity (targetValue - current assignedValue) for each group. Pick randomly from top candidates (those within 80% of best gap). Assign item to chosen group. Returns new groups array with assignedItems, assignedValue, and cashAdjustment populated.
    - `moveItem(groups, items, itemId, fromHeirType, toHeirType)`: Creates new groups array. Removes itemId from source group's assignedItems, adds to target group's assignedItems. Recalculates assignedValue for ALL groups (not just affected pair) using items lookup. Recalculates cashAdjustment. Returns new groups.
    - `calculateDistributionCompensations(groups)`: Same pattern as Phase 9's calculateCompensations -- pairs overfilled with underfilled groups greedily.
    - `initializeDistribution(properties, movableAssets, shares, totalEstateValue)`: Creates DistributionResult by building items, creating groups from active shares, and running smartShuffle as initial assignment.

    Use imports from existing modules: `computePropertyTotal` from `@/core/land/types`, `computeAssetValue` from `@/core/assets/valuation`, `HEIR_TYPE_LABELS` from `@/core/utils/display`.

    - moveItem updates groups and sets previousSnapshot; calling undo restores previous groups

  <action>
    Create `src/stores/distributionStore.ts` following the ephemeral Zustand store pattern from divisionStore.ts (no persist middleware, reads wizardStore via getState()). This store REPLACES divisionStore for the distribution page -- divisionStore remains for backward compatibility.

    **State fields:**
    - `distributionResult: DistributionResult | null`
    - `previousSnapshot: DistributionGroup[] | null` (one-level undo)
    - `fingerprint: string | null` (for staleness detection)

    **Actions:**
    - `computeDistribution()`: Reads properties, movableAssets, results, totalEstateValue from wizardStore.getState(). Calls initializeDistribution from algorithm.ts. Sets distributionResult and fingerprint. Clears previousSnapshot.
    - `randomize()`: Saves current groups as previousSnapshot (structuredClone). Calls smartShuffle on current items and groups (resetting assignedItems/assignedValue). Updates groups and compensations.
    - `moveItem(itemId, fromHeirType, toHeirType)`: Saves current groups as previousSnapshot. Calls algorithm.moveItem. Updates groups and recalculates compensations.
    - `undo()`: If previousSnapshot exists, restores groups from it, recalculates compensations, and clears previousSnapshot.
    - `isStale()`: Compares current fingerprint with freshly computed one. Fingerprint includes property IDs + values AND movable asset IDs + values (fixes the Phase 9 fingerprint issue noted in RESEARCH.md pitfall 5).
    - `getEquilibriumSummary()`: Returns `{ balanced: number, total: number }` by computing getEquilibriumStatus for each group.
    - `resetDistribution()`: Clears all state.

    **computeFingerprint():** JSON.stringify of `[...properties.map(p => ({id: p.id, v: computePropertyTotal(p)})), ...movableAssets.map(a => ({id: a.id, v: computeAssetValue(a)}))]`.

    Create comprehensive store tests in `src/stores/__tests__/distributionStore.test.ts`. Mock wizardStore.getState() to return test data with properties and movable assets. Test all actions including undo behavior.
