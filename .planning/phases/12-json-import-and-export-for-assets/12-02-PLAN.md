       - Props: `onFileSelected: (file: File) => void`
       - Visual: dashed border box with upload icon, "Drag JSON file here or click to browse" text, muted text color
       - Drag-over state: use counter pattern (dragenter increments, dragleave decrements) to prevent child-element flicker. When counter > 0, show emerald border + emerald bg-opacity-5 highlight
       - Set `e.dataTransfer.dropEffect = 'copy'` on dragover, `e.preventDefault()` on dragover and drop
       - On drop: reset counter to 0, extract first file, call `onFileSelected(file)`
       - Hidden `<input type="file" accept=".json,application/json">` triggered on click
       - Guard: reject files > 1MB with early return (let the hook handle the error toast)
       - Compact layout: should not dominate Step 1 -- render as a secondary option below a divider ("or import from file")

    4. Create `src/hooks/useJsonExport.ts`:
       - `useJsonExport()` returns `{ exportJson: () => void }`
       - On call: `useWizardStore.getState()` (non-reactive, like usePdfExport pattern)
       - Call `extractExportData(state)` and `generateExportFilename(state)`
       - `JSON.stringify(exportData, null, 2)` for pretty-printed output
       - Create Blob with `type: 'application/json'`, create object URL, create anchor element, set `href` and `download` attributes, click, remove anchor, revoke URL (same pattern as usePdfExport)

    5. Create `src/hooks/useJsonImport.ts`:
       - `useJsonImport()` returns `{ importFromFile: (file: File) => void, pendingState: WizardState | null, confirmImport: () => void, cancelImport: () => void, toast: { message: string | null; type: 'success' | 'error' }, dismissToast: () => void }`
       - `importFromFile(file: File)`:
         a. Check `file.size > 1_000_000` -> set error toast "File too large (max 1MB)" and return
         b. Check file name ends with `.json` or file.type is `application/json` -> set error toast "Please select a JSON file" if not
         c. Read file with FileReader.readAsText
         d. In onload: JSON.parse the result. On parse error -> set error toast "Invalid file -- could not parse JSON"
         e. Call `validateAndParseImport(parsed)`. On failure -> set error toast with the error message
         f. On success: set `pendingState` to the validated WizardState (triggers confirmation dialog)
       - `confirmImport()`:
         a. Call `useWizardStore.setState(pendingState, true)` for atomic state replacement
         b. Call `useDistributionStore.getState().resetDistribution()` to clear stale ephemeral state
         c. Clear pendingState
         d. Set success toast "Data imported successfully"
       - `cancelImport()`: clear pendingState
       - Toast state: `{ message, type }` managed via useState, `dismissToast` sets message to null
