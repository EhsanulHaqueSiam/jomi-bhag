    **Step 1: Create `src/components/results/chartData.ts` -- shared data derivation module.**

    Export:
    - `ChartDatum` interface: `{ name: string, value: number, bdtValue: number, fraction: string, percentage: string, bdtAmount: string, fill: string }`
    - `EMERALD_COLORS` array: 8 hex colors from Tailwind emerald scale -- use hex values for SVG compatibility: `['#10b981', '#059669', '#047857', '#34d399', '#065f46', '#6ee7b7', '#0d9488', '#14b8a6']`
    - `buildChartData(activeShares: ShareResult[], totalEstateValue: number): ChartDatum[]` function:
      - For each share: label from HEIR_TYPE_LABELS, append ` x${count}` when count > 1
      - `value` = `share.totalShare.valueOf() * 100` (percentage for pie)
      - `bdtValue` = `Math.round(share.totalShare.valueOf() * totalEstateValue)` (for bar)
      - `fraction` = `share.totalShare.toFraction()`
      - `percentage` = `fractionToPercent(share.totalShare)`
      - `bdtAmount` = `fractionToBDT(share.totalShare, totalEstateValue)`
      - `fill` = `EMERALD_COLORS[i % EMERALD_COLORS.length]`
