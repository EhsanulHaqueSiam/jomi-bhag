# Jomi-Bhag (জমি ভাগ)

Islamic inheritance (Faraid) land & property division calculator for Bangladeshi families.

**Live:** [jomibhag.netlify.app](https://jomibhag.netlify.app)

## What it does

Helps Bangladeshi families and legal professionals calculate and visualize property shares strictly according to Faraid (Islamic inheritance law). Enter heir details, property information, and get precise share breakdowns with Quranic/Hadith references.

- Strict Hanafi jurisprudence — every calculation traceable to Quran & Sunnah
- Exact fraction arithmetic — no floating-point rounding errors
- All 16 Hajb blocking rules + Awl/Radd adjustments
- Special cases: Umariyyatayn, Mushtarakah, Kalalah
- MFLO Section 4 opt-in toggle for orphaned grandchildren
- Simple mode for families, detailed mode for legal professionals

## Tech Stack

React · TypeScript · TailwindCSS 4 · Vite · Bun · Netlify

## Development

```bash
bun install
bun run dev
```
